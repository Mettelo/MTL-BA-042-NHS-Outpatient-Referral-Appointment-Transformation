# NHS RTT contextual data register

The planned 2026–27 download endpoint returned a bot check during preparation. No real RTT file is claimed as downloaded here. The case pack remains usable with synthetic evidence; external contextual analysis must be labelled pending until an official file is acquired.

Use https://www.england.nhs.uk/statistics/statistical-work-areas/rtt-waiting-times/rtt-data-2026-27/ and select one published monthly full CSV or provider file. Record exact URL, reporting month, publication/revision date, retrieval date, filename, hash, licence/attribution and selected population. Retain the original file separately from synthetic records. Check missing-provider and revision notes.
Incomplete pathways are not first-appointment administrative waits. Do not join the fictional trust to a real provider code or treat national measures as its baseline.
