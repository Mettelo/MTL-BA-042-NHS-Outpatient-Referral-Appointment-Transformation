# Mettelo BA-042 — source navigation

Use this catalogue to locate the evidence named in the project brief. It is an index, not a set of findings. Check [the release manifest](../project/RELEASE_MANIFEST.csv) before opening files in a controlled cohort.

## How to read the sources

Start with the business context and stakeholder testimony. When release 2 opens, read DATA_GUIDE before calculating from CSVs, then inspect the pathway-specific supplement and existing policy/system context. Compare records with testimony; neither alone proves every claimed cause. Release 3 contains challenge evidence. Release 4 is optional later experiment background and must not be claimed as testing you executed.

The source-to-task table in [the project brief](../project/PROJECT_BRIEF.md) explains why each group matters.
